Summer School Preparation

The 3rd Process Mining Summer School is less than one week away!

To make the most of your experience, it is very important that you complete some preparation before coming to Pohang. Please read the following instructions carefully.

1 Bring your laptop

Please bring your own laptop to all classes. The Summer School features highly interactive sessions using state-of-the-art process mining tools.

2 Install the required tools

Please install the following tools on your laptop and download the datasets that will be used during the lectures.

ProM

Windows & other platformsRequires Java 8Free / open source

Obtain ProM from the ProM website. Please install either ProM 6.15 or ProM Lite 1.4.

If you encounter difficulties, you may use our Docker-based solution. Please refer to the installation video.

Celonis

Any platform (web browser)Academic EditionRegistration required

Obtain access to the Celonis Academic Edition through the Celonis registration page. You can also visit the Celonis Academic website for additional resources.

Because Celonis runs in a web browser, it is available on any platform. Please refer to the Celonis tutorial video.

Disco

Windows & macOSUniversity email requiredFree version sufficient

Download and install Disco from the Fluxicon website. After installation, you must register with your email address to use the tool — please use your university email address.

Many universities in Korea and abroad have academic license agreements with Fluxicon, which provide access to the full version. Even if your university does not have such an agreement, you will still be able to use the free version. The free version has a limitation on dataset size, but it will be sufficient for the Summer School.

In addition, please review the following resources, which will be referenced in the lecture on data foundations for process mining:

  • Data extraction
  • Data extraction checklist

You do not need to watch the full ProM and Celonis videos in advance. However, please verify that you can upload at least the case-centric datasets and perform some basic analyses, such as discovering directly-follows graphs (DFGs) and BPMN models.
